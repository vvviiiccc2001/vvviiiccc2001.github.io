## 格式要求（GitHub 限制）

- 格式：MP4（H.264），浏览器原生可播；HEVC/ProRes/MOV 原片请先转码
- 单条 ≤ 100 MB（GitHub 硬上限）；建议 720p、码率 2–5 Mbps
- **相机直出原片不要留在这个文件夹**——会被一起 push 上去
- 想加新项目：在 `index.html` 复制一张卡片，视频槽 `src` 写新名字，视频同名放入本文件夹
